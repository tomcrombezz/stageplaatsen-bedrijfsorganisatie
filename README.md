# Stageplaatsen Bedrijfsorganisatie — De MET

Statische informatieve website voor bedrijven die een stageplaats willen aanbieden aan leerlingen Bedrijfsorganisatie van De MET.

## Publiceren

De website is bedoeld voor GitHub Pages. De workflow in `.github/workflows/deploy.yml` publiceert de bestanden automatisch na een push naar `main`. Stel in de repository bij **Settings → Pages** de bron in op **GitHub Actions**. De repository moet openbaar zijn om GitHub Pages met GitHub Free te gebruiken.

De site gebruikt alleen HTML, CSS en een logo in `assets/`; er is geen buildstap nodig.
